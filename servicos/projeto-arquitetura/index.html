Projeto de arquitetura: da intenção a um projeto que as outras disciplinas conseguem seguir

Antes de coordenar disciplinas, é preciso transformar intenção e restrição em espaço possível.

O projeto de arquitetura organiza aquilo que o empreendimento pretende ser e cria uma base capaz de conversar com estrutura, instalações, terreno e exigências do caso.

Para quem é

Pode fazer sentido em:

  • construções novas;
  • ampliações;
  • desenvolvimento de uma intenção ainda não transformada em projeto coordenável;
  • situações em que arquitetura precisa evoluir junto das demais disciplinas.

Entregáveis

Podem incluir, conforme o nível e o escopo contratados:

  • estudos;
  • projeto legal;
  • projeto básico;
  • projeto executivo;
  • pranchas;
  • arquivos digitais;
  • modelos tridimensionais;
  • IFC;
  • memoriais;
  • ART;
  • demais produtos expressamente definidos na proposta.

Nenhum desses itens deve ser entendido como pacote automático de toda contratação.

O que muda para você

Uma base que conversa com o resto

A arquitetura vira uma base que conversa com estrutura, instalações, terreno e exigências do caso.

Você contrata o nível que precisa

Estudo preliminar, projeto legal, básico e executivo são etapas diferentes. O escopo define quais entram.

Nada de pacote automático

Nenhum item da lista de entregáveis é pacote de toda contratação.

Como funciona

  1. Conte o seu caso

    Abra a estimativa com “Arquitetura” já selecionado e responda só ao que se aplica ao seu caso. Você informa a área do projeto. Não sabe a área? Conta o que imagina para a casa e/ou informa o terreno: estimamos uma área de referência para o orçamento, sem consultar legislação. Sem nada disso, a equipe avalia.

  2. Veja a estimativa

    Com informação suficiente, o valor inicial aparece na própria página, antes de qualquer contato. Se o caso pedir avaliação, você recebe o enquadramento.

  3. Escolha o próximo passo

    Receber uma proposta ou tirar uma dúvida sobre o escopo. Só então pedimos o seu contato.

  4. Escopo definido na proposta

    O nível e o conteúdo final do serviço são confirmados pela equipe e definidos na proposta.

O que a DEMELLO faz

A DEMELLO desenvolve arquitetura a partir das necessidades do empreendimento e do nível contratado.

A cadeia de desenvolvimento pode envolver, conforme a proposta:

  • estudo preliminar;
  • projeto legal;
  • projeto básico;
  • projeto executivo.

Nem toda contratação passa por todas essas etapas; o escopo define quais fazem parte do trabalho.

Como o escopo é definido

A definição pode considerar:

  • construção ou ampliação;
  • intenção do empreendimento;
  • restrições existentes;
  • área;
  • tipologia;
  • número de pavimentos;
  • fase;
  • localização;
  • documentação e levantamentos disponíveis;
  • nível de desenvolvimento pretendido.

Experiência aplicada — CECM Djalma Marinho

No CECM Djalma Marinho, Marcos respondeu pelo projeto arquitetônico de um conjunto com forte condicionante de implantação: aproximadamente 16 metros de desnível, nove blocos existentes e uma ampliação que levaria o conjunto a dez.

O projeto incluiu doze rampas integrando os espaços e reorganização funcional dentro do conjunto.

A atuação ocorreu antes da DEMELLO Engenharia.

Escopo e limites

Arquitetura e regularização podem se relacionar, mas são serviços distintos. Procedimentos de regularização, levantamentos específicos e atuação administrativa só integram o trabalho quando previstos no escopo.

O nível de desenvolvimento também precisa ser identificado com clareza.

Estudo preliminar, projeto legal, projeto básico e projeto executivo são produtos e etapas diferentes.
