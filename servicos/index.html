Projetos para construir ou ampliar

Arquitetura, estrutura e instalações têm funções diferentes. Veja qual projeto atende à sua demanda.

01

Projeto de arquitetura

Precisa da planta de casa ou de outro projeto de arquitetura? O que você pretende construir vira a base para os demais projetos.

Estudo preliminar, projeto legal, básico e executivo são etapas diferentes. Regularização não está incluída automaticamente.

Ver o serviço →: Projeto de arquitetura
02

Projeto estrutural

A estrutura precisa funcionar com a arquitetura e deixar espaço para as instalações. O projeto pode abranger a estrutura da obra ou somente a fundação, conforme o caso.

Não inclui execução da obra.

Ver o serviço →: Projeto estrutural
03

Projeto hidrossanitário

Água, esgoto e drenagem precisam funcionar juntos. O projeto hidrossanitário organiza essas redes para obra nova, ampliação ou uma rede já existente.

Drenagem entra aqui, sem cobrança separada. Não inclui execução das instalações.

Ver o serviço →: Projeto hidrossanitário
04

Projeto de incêndio — PPCI

A prevenção contra incêndio precisa entrar nas decisões de projeto. O PPCI considera os encontros com a arquitetura e as demais disciplinas.

Incêndio e gás são serviços distintos. A contratação do projeto não garante aprovação pelo órgão competente.

Ver o serviço →: Projeto de incêndio — PPCI
05

Projeto de gás / GLP

A instalação de gás começa no projeto. O projeto de gás / GLP considera o uso da edificação e os encontros com as demais disciplinas.

Não se funde com o projeto de incêndio. Projeto não é instalação e não presume aprovação garantida.

Ver o serviço →: Projeto de gás / GLP
06

Projeto de terraplanagem

Antes de mexer na terra, é preciso resolver como a obra se encaixa no terreno. O projeto de terraplanagem trata essa relação, coordenado com os demais projetos.

Também chamada de terraplenagem. A DEMELLO não executa movimentação de terra.

Ver o serviço →: Projeto de terraplanagem
07

Compatibilização BIM

Coordenar as disciplinas e as interfaces do projeto antes que a obra descubra os conflitos por conta própria.

Não presume autoria de todos os projetos nem ausência de conflitos.

Ver o serviço →: Compatibilização BIM

Para arquitetos e construtoras

Já tem a arquitetura e precisa dos projetos complementares? Veja as disciplinas acima. Se os projetos vieram de profissionais diferentes, conheça a compatibilização BIM.

Regularização de imóveis, orçamento e cronograma

O imóvel já existe. Ou o escopo da obra já está definido. Veja o que precisa ser organizado para seguir.

08

Regularização de imóvel

O imóvel não bate com os documentos? Há uma exigência de prefeitura ou cartório? Primeiro se descobre o que está irregular. Depois, qual caminho o caso exige.

Não é um pacote universal: levantamento e projeto legal entram só quando necessários e contratados. Sem promessa de aprovação automática.

Ver o serviço →: Regularização de imóvel
09

Orçamento e cronograma

Já sabe o que será feito? O orçamento e o cronograma organizam as informações desse escopo para você planejar e decidir.

É um serviço profissional contratado, diferente da estimativa deste site. Não promete o custo final da obra.

Ver o serviço →: Orçamento e cronograma
