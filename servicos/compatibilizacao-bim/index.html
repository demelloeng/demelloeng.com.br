Arquitetura, estrutura e instalações dividem o mesmo espaço. Compatibilizar é fazer essas decisões combinarem antes da obra. No trabalho em BIM, modelos e informações ajudam a localizar essas incompatibilidades.

A DEMELLO coordena esse trabalho entre as disciplinas, em projetos dela ou de outros escritórios.

Quando vale compatibilizar

Faz sentido quando:

  • arquitetura, estrutura e instalações vêm de escritórios diferentes;
  • uma revisão na arquitetura mexe na estrutura ou nas instalações;
  • duas disciplinas disputam o mesmo lugar: laje, forro, shaft, parede;
  • o projeto vai para orçamento ou para a obra sem conferir as interfaces;
  • uma reforma exige integrar novas instalações à arquitetura e à estrutura existentes.

O que muda para você

Interferências identificadas antes da obra

A análise das interfaces entre instalações, estrutura e arquitetura ajuda a encontrar incompatibilidades enquanto ainda é possível discutir os ajustes no projeto.

A decisão é tomada com tempo

Quem decide é a equipe de projeto, com calma. Não a obra, com pressa.

Menos retrabalho no canteiro

Resolver conflitos no projeto reduz o risco de quebra, atraso e retrabalho no canteiro.

O que a DEMELLO faz

A DEMELLO coordena as disciplinas como um conjunto. Na prática:

  • analisa onde os projetos se encontram;
  • identifica interferências e incompatibilidades;
  • coordena as decisões técnicas para resolver cada conflito;
  • encaminha a cada responsável técnico as alterações da disciplina dele;
  • verifica se as soluções se integram, dentro do escopo contratado.

Projeto de outro profissional: a DEMELLO aponta o conflito e coordena a solução. Quem altera é o responsável técnico daquela disciplina.

Projeto sob responsabilidade técnica da DEMELLO: o ajuste é feito direto.

A DEMELLO responde pela coordenação; cada autor, pelo seu projeto.

Das interfaces às decisões coordenadas

  1. Leitura dos projetosA DEMELLO analisa os projetos e documentos que você já tem.
  2. InterferênciasIdentifica onde as disciplinas se cruzam e o que não combina.
  3. CoordenaçãoLeva cada conflito aos responsáveis e coordena a solução.
  4. IntegraçãoConfere se as decisões se encaixam, dentro do escopo contratado.

A ordem pode mudar conforme o caso. O que você recebe em cada etapa é definido na proposta.

Perguntas frequentes

Meus projetos estão em PDF ou DWG. Serve?

Podem servir como ponto de partida. A DEMELLO recebe projetos em PDF, DWG, DXF ou IFC. A forma de utilizar esses arquivos e a eventual necessidade de modelagem dependem das condições do material e do escopo contratado.

Preciso ter todos os projetos prontos?

Não. Dá para compatibilizar com o projeto em andamento. Quanto antes as incompatibilidades são identificadas, mais cedo é possível discutir as soluções. O estágio de cada projeto entra no escopo.

A compatibilização garante uma obra sem conflito?

Conflito zero não existe. A compatibilização traz para o projeto as interferências que os documentos permitem ver. Quanto mais completos os projetos, menos a obra descobre sozinha.

Compatibilização é o mesmo que detecção de interferências?

Não. A detecção identifica possíveis interferências entre elementos dos modelos. A compatibilização vai além: analisa os conflitos, coordena as soluções entre disciplinas e verifica os ajustes.

BIM é uma metodologia de trabalho baseada na integração de modelos e informações. Os softwares apoiam esse processo. As decisões técnicas continuam com os profissionais responsáveis.

Conheça como a DEMELLO trabalha com BIM.

Compatibilização e orçamento são o mesmo serviço?

Não. A compatibilização faz os projetos combinarem. O orçamento transforma o projeto em custo e prazo. Os dois se complementam. Veja Orçamento e cronograma.

Detalhes do escopo

O que define o escopo:

  • as disciplinas que entram na coordenação;
  • quantas interfaces existem entre elas;
  • a área do escopo;
  • o estágio de cada projeto;
  • o responsável técnico de cada projeto;
  • o formato e a condição dos arquivos.

Como funciona a estimativa: a calculadora usa a área do escopo. Com informação suficiente, o valor inicial aparece na tela, antes de qualquer contato. A estimativa não é proposta nem contrato. Formatos de entrega e rodadas de revisão são definidos na proposta.
